# TuteDude MERN Stack – Task 2: CSS Selectors

## Files Included

- `index.html` – Main HTML file
- `style.css` – External CSS stylesheet
- `README.md` – Project documentation

## How to Run

1. Download and unzip the project folder.
2. Open `index.html` in a web browser such as Chrome or Firefox.
3. Make sure `style.css` is in the same folder as `index.html`.

## CSS Selectors Used

| Selector Type | Where Used |
|---|---|
| Element selector | `body`, `p` |
| Class selector | `.head` – all 3 headings |
| ID selector | `#bglime` – second heading background |
| ID selector | `#para` – second paragraph styling |
| Descendant selector | `#bglime span` – red "head" word |
| Descendant selector | `#para span` – black "paragraph" word |
| Attribute selector | `ul li a[href]`, `ol li a[href]` – "here" links |

## Task Steps Completed

- Step 1: Created `index.html` and `style.css`.
- Step 2: Linked `style.css` to `index.html`.
- Step 3: Set the body background color using an element selector.
- Step 4: Created 3 headings (`h1`, `h2`, `h3`) with `class="head"`.
- Step 5: Applied dark blue text color to all elements with `class="head"`.
- Step 6: Applied a lime background to the second heading using `id="bglime"`.
- Step 7: Styled the "head" word in the second heading red using a descendant selector.
- Step 8: Created 3 paragraphs and styled them using the `p` element selector.
- Step 9: Customized the second paragraph using `id="para"`.
- Step 10: Styled the "paragraph" word inside `#para` with black color and larger font size.
- Step 11: Styled the "here" links in both lists using an attribute selector.
